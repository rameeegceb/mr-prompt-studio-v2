# Mr. Prompt Studio — Project Overview

## Business purpose
Mr. Prompt Studio is built to help enterprise users design, improve, and manage prompts for AI applications. It provides learning content, prompt templates, and a studio environment for prompt engineering.

## Current objectives
- Deliver the Learning Hub as a content-driven training experience.
- Deliver the Prompt Studio workbench for prompt improvement and evaluation.
- Deliver the Prompt Library for template discovery and reuse.
- Provide AI provider configuration and an AI test console.

## Target users
- Prompt engineers
- AI product managers
- Enterprise knowledge workers
- Developers integrating AI prompts

## Current features
- Learning Hub with course metadata, chapters, bookmarks, favorites, and content rendering.
- Prompt Studio with a prompt editor, improve/evaluate/convert actions, analysis panel, and output.
- Prompt Library with template filters, gallery, favorites, recent items, and preview.
- Settings page with provider configuration.
- AI test page for manual prompt execution.

## Current roadmap (based on implementation)
- Stabilize the Learning Hub content experience.
- Complete prompt improve vertical slice in Prompt Studio.
- Extend Prompt Library search, categories, and data-driven templates.
- Expand Best Practices feature (currently placeholder).
- Complete Prompt Builder/Studio mode integration.

## Feature relationships
- Learning Hub is content-driven and independent of prompt tooling.
- Prompt Library supports prompt reuse and template loading.
- Prompt Studio is the execution workspace for prompt editing and evaluation.
- Settings configures AI providers used by prompt execution.
